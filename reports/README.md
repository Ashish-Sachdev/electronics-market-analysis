# Reports

This folder turns the notebook into material that a teammate, instructor or recruiter can understand without reading every notebook cell.

## Files
- `analysis_summary.md` — what the current notebook analyses and how to interpret it.
- `predictive_model_guide.md` — beginner-friendly plan for building a price-prediction model.
- `model_results_template.md` — fill this after the model is run on the final cleaned CSV.
- `figures/` — export only presentation-ready charts that are actually used in the README, report or presentation.

## Rule
Do not copy conclusions into this folder unless they can be traced back to the current notebook/data. If a notebook result changes, update the written report too.
