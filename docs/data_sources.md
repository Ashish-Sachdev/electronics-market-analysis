# Data Source

## Source used by this project
The repository contains the original file:

```text
data/raw/ElectronicsProductsPricingData.csv
```

The team's analysis notebook uses a collaboratively cleaned version named:

```text
electronics_pricing_clean.csv
```

In the saved notebook run this cleaned file contains **7,235 rows and 35 columns**.

## Current storage mismatch
The notebook currently loads the cleaned file from a personal Google Drive path. The GitHub repository does not currently contain `data/processed/electronics_pricing_clean.csv`.

For a reproducible team submission, either:
1. add the cleaned CSV to `data/processed/` if distribution is permitted, or
2. document exactly where teammates obtain it and keep the relative filename/path consistent.

## Scope warning
This is historical product/listing pricing data. It should not be described as complete current-market coverage or as completed sales transaction data.
