# Contributing

This repository is designed for an eight-person, 10-day analytics project.

1. Create or choose a GitHub issue.
2. Pull the latest `main`.
3. Create a focused branch such as `feature/ingestion`, `analysis/eda`, `dashboard/pricing`,
   `test/data-quality`, or `docs/kpis`.
4. Make one coherent change at a time.
5. Run relevant tests before pushing.
6. Open a pull request explaining what changed, how it was checked, and any limitations.
7. Ask the assigned reviewer to check it before merging.

Do not commit `.env`, credentials, virtual environments, raw downloaded datasets, generated DuckDB databases, model binaries or temporary outputs.
